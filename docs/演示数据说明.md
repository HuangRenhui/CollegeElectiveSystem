# 演示数据说明

> 本文档说明项目内置的演示数据：包含什么、如何使用、以及各页面能看到的效果。
>
> 演示数据用于**功能演示、验收测试与二次开发**，让系统初始状态即具备完整业务内容，
> 无需人工逐条录入。

---

## 1. 快速使用

### 方式一：一键初始化（建表 + 基础数据 + 演示数据）

```bash
cd CollegeElectiveSystem

# 脚本会自动切换目标库，无需手工指定
mysql -uroot -p < scripts/init-db.sql
```

### 方式二：仅补充演示数据（表结构与基础数据已就绪）

```bash
mysql -uroot -p <目标库> < scripts/init-demo-data.sql
```

### 方式三：Docker 环境

```bash
# 容器启动后执行（容器首次启动已自动完成建表与基础数据）
docker exec -i elective-mysql mysql -uroot -proot123456 college_elective \
  < backend/src/main/resources/db/demo-data.sql
```

> **提示**：开发环境下应用启动时会**自动创建缺失的表结构**，
> 因此实际只需导入 `data.sql` 与 `demo-data.sql` 两个数据脚本。

## 3. 数据设计说明

### 3.1 学期分布

| 学期 | 编码 | 状态 | 用途 |
| --- | --- | --- | --- |
| 第一学期 | `2025-2026-1` | 已结束 | 提供历史成绩数据（用于成绩单） |
| 第二学期 | `2025-2026-2` | 已结束 | 提供历史成绩数据 |
| **当前学期** | `2026-2027-1` | **选课中** | 选课、课表的主数据来源 |

### 3.2 选课记录构成

```
44 条  当前学期已选课（status=1）  → 选课中心、我的课表、学生名单
35 条  历史学期已修完（status=2）  → 成绩单、绩点统计
 1 条  已退选（status=0）          → 演示退选状态
```

### 3.3 成绩数据构成

| 状态 | 数量 | 用途 |
| --- | ---: | --- |
| 已发布（status=1） | 35 | 学生端成绩单可见 |
| 草稿（status=0） | 5 | 教师端「待发布」场景演示 |

**成绩覆盖分数段**（让统计图表有形状）：

| 分数段 | 说明 |
| --- | --- |
| 90 分以上 | 绩点 4.0 |
| 80-89 分 | 绩点 3.7 |
| 70-79 分 | 绩点 2.7 |
| 60-69 分 | 绩点 1.0-1.5 |
| 60 分以下 | 不及格（含重修标记） |

### 3.4 数据自洽性保障

脚本末尾通过 SQL 自动重算，确保数据一致：

```sql
-- 课程已选人数 = 该课程 status=1 的选课记录数
UPDATE course c SET c.selected_count = (...);

-- 学生已获学分 = 已修完且及格课程的学分之和
UPDATE student s SET s.total_credit = (...);
```

**时间冲突校验**：全部 44 条当前学期选课组合均通过四维冲突检测（同天 + 节次 + 周次 + 单双周），
无任何冲突，与系统的选课校验逻辑保持一致。

### 3.5 可重复执行

脚本开头会清理本系统的业务数据后重建：

```sql
DELETE FROM course_grade;
DELETE FROM course_selection;
DELETE FROM sys_log;
UPDATE course SET selected_count = 0;
```

- 仅清理这 3 张表，**不影响** `data.sql` 中的院系、专业、用户、课程等基础数据；
- 其余表使用 `ON DUPLICATE KEY UPDATE`，重复执行不会产生重复记录；
- 若部署在其他业务库中，**不会影响该库的既有数据**。

## 6. 验证数据是否导入成功

```sql
SELECT '院系' AS 数据表, COUNT(*) AS 记录数 FROM department
UNION ALL SELECT '专业', COUNT(*) FROM major
UNION ALL SELECT '用户', COUNT(*) FROM sys_user
UNION ALL SELECT '学生', COUNT(*) FROM student
UNION ALL SELECT '教师', COUNT(*) FROM teacher
UNION ALL SELECT '课程', COUNT(*) FROM course
UNION ALL SELECT '选课记录', COUNT(*) FROM course_selection
UNION ALL SELECT '成绩记录', COUNT(*) FROM course_grade
UNION ALL SELECT '操作日志', COUNT(*) FROM sys_log;
```

**预期结果**：5 / 9 / 29 / 20 / 8 / 17 / 80 / 40 / 23

## 7. 清空演示数据

如需恢复为空白状态（保留表结构与基础数据）：

```sql
DELETE FROM course_grade;
DELETE FROM course_selection;
DELETE FROM sys_log;
UPDATE course SET selected_count = 0;
UPDATE student SET total_credit = 0.0;
```

若需恢复到仅含 `data.sql` 的状态，重新执行 `data.sql` 即可。
