# 环境安装指南（Windows）

> 本文档面向 Windows 开发者，说明如何安装并初始化本项目所需的 MySQL 与 Redis。
>
> **提示**：开发环境下**表结构会自动创建**——只要数据库连接配置正确，
> 应用启动时会自动检测并创建缺失的数据表，无需手工执行建表脚本。
> 详见 [第 4 节 数据库初始化](#4-数据库初始化)。

---

## 1. 现状诊断

执行以下命令可确认环境状态：

```powershell
# 检查端口占用
Test-NetConnection -ComputerName localhost -Port 3306   # MySQL
Test-NetConnection -ComputerName localhost -Port 6379   # Redis
Test-NetConnection -ComputerName localhost -Port 8080   # 后端
Test-NetConnection -ComputerName localhost -Port 5174   # 前端
```

| 服务 | 端口 | 当前状态 | 影响 |
| --- | --- | --- | --- |
| 前端 | 5174 | ✅ 已就绪 | - |
| 后端 | 8080 | ✅ 可启动 | 依赖数据库的接口报 500 |
| **MySQL** | 3306 | ❌ 未安装 | 登录、课程、成绩等全部数据接口不可用 |
| **Redis** | 6379 | ❌ 未安装 | 登录后写入令牌缓存会失败 |

## 2. 安装 MySQL

### 方式一：winget 安装（推荐）

以**管理员身份**打开 PowerShell：

```powershell
winget install --id Oracle.MySQL --accept-package-agreements --accept-source-agreements
```

> 如 winget 未找到该包，可先执行 `winget search mysql` 查看可用包名。

### 方式二：官网安装包

1. 访问 <https://dev.mysql.com/downloads/installer/>
2. 下载 **MySQL Installer for Windows**（约 300MB）
3. 安装时选择 **Server only** 或 **Custom**（仅需 MySQL Server）
4. 配置向导中：
   - **Authentication Method**：选择 `Use Legacy Authentication Method`
   - **Root Password**：设置为 `123456`（与项目默认配置一致；如用其他密码，需同步修改下方配置文件）
   - **Windows Service**：勾选 `Configure MySQL Server as a Windows Service`，服务名默认 `MySQL80`
   - 勾选 `Start the MySQL Server at System Startup`

### 方式三：免安装版（ZIP）

1. 下载 <https://dev.mysql.com/downloads/mysql/> 的 ZIP Archive
2. 解压到 `D:\mysql-8.0`
3. 在解压目录新建 `my.ini`：

```ini
[mysqld]
basedir=D:\mysql-8.0
datadir=D:\mysql-8.0\data
port=3306
character-set-server=utf8mb4
collation-server=utf8mb4_general_ci
default-time-zone='+08:00'

[client]
default-character-set=utf8mb4
```

4. 初始化并安装服务（管理员 PowerShell）：

```powershell
cd D:\mysql-8.0\bin
.\mysqld --initialize-insecure --user=mysql
.\mysqld --install MySQL80
net start MySQL80

# 设置 root 密码
.\mysql -uroot --skip-password
```

在 MySQL 提示符下执行：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';
FLUSH PRIVILEGES;
EXIT;
```

### 验证 MySQL

```powershell
# 检查服务状态
Get-Service MySQL80

# 检查端口
Test-NetConnection -ComputerName localhost -Port 3306

# 登录测试
mysql -uroot -p123456 -e "SELECT VERSION();"
```

## 3. 安装 Redis

> **重要**：Redis 官方仅支持 Linux。Windows 上使用以下方案之一。

### 方案 A：Memurai（推荐，最省事）

Memurai 是 Redis 的 Windows 原生实现，兼容 Redis 协议：

```powershell
winget install --id Memurai.MemuraiDeveloper --accept-package-agreements --accept-source-agreements
```

安装后会自动注册为 Windows 服务并启动，**默认端口 6379，无密码**，与项目默认配置一致。

验证：

```powershell
Get-Service Memurai
Test-NetConnection -ComputerName localhost -Port 6379
```

### 方案 B：WSL2 中运行 Redis

若已启用 WSL2，在 WSL 终端中执行：

```bash
sudo apt update
sudo apt install -y redis-server
sudo service redis-server start
redis-cli ping     # 期望输出 PONG
```

> WSL2 默认与 Windows 共享 localhost，因此 Windows 侧的 `localhost:6379` 可直接访问。

### 方案 C：微软归档版 Redis（旧版本）

1. 下载 <https://github.com/microsoftarchive/redis/releases> 的 `Redis-x64-3.0.504.zip`
2. 解压到 `D:\Redis`
3. 安装为服务（管理员 PowerShell）：

```powershell
cd D:\Redis
.\redis-server --service-install redis.windows.conf
.\redis-server --service-start
```

### 验证 Redis

```powershell
redis-cli ping
# 期望输出：PONG
```

## 4. 初始化数据库

### 4.1 表结构：启动时自动创建（推荐）

**开发环境下无需手工建表**。只要数据库连接配置正确，应用启动时会自动：
1. 读取 `db/schema.sql` 中的建表语句；
2. 检查每张表是否已存在；
3. 仅创建**缺失的表**，已存在的表不会被修改或删除。

启动日志示例：

```
DatabaseInitializer - 检测到 13 张缺失数据表，开始自动创建：[sys_user, department, ...]
DatabaseInitializer -   创建数据表 [sys_user] 成功
...
DatabaseInitializer - 数据库表结构初始化完成，成功创建 13 张表（耗时 7895 ms）
```

二次启动时（表已存在）：

```
DatabaseInitializer - 数据库表结构检查完成，13 张表均已存在，无需初始化（耗时 989 ms）
```

**生效范围**：

| 环境 | 是否自动建表 | 说明 |
| --- | --- | --- |
| `dev`（默认） | ✅ 启用 | 启动时自动补全缺失表 |
| `prod` | ❌ 禁用 | 表结构变更须经审核后手工执行 |

可通过配置项显式控制：

```yaml
elective:
  database:
    auto-init: true    # false 可关闭
```

> **安全保障**：自动初始化**只建表、不删数据**。脚本中的 `DROP TABLE` 会被过滤，
> 已存在的表不会被重建，重复启动无副作用。

### 4.2 基础数据与演示数据：需手工导入

表结构自动创建后，**数据仍需要手工导入**（避免生产环境误插入测试数据）：

```powershell
cd d:/codemanager/CollegeElectiveSystem

# 一键导入（基础数据 + 演示数据）
mysql -uroot -p123456 < scripts/init-db.sql
```

或分步执行：

```powershell
# 1. 建库建表（自动初始化已建表时可跳过；手工建表时执行）
mysql -uroot -p123456 < backend/src/main/resources/db/schema.sql

# 2. 基础数据（院系、专业、用户、课程等）
mysql -uroot -p123456 < backend/src/main/resources/db/data.sql

# 3. 演示数据（选课记录、成绩、操作日志）
mysql -uroot -p123456 < backend/src/main/resources/db/demo-data.sql
```

若 mysql 客户端不可用，也可通过数据库工具（Navicat / DBeaver / MySQL Workbench）
直接打开上述 `.sql` 文件执行。

## 5. 配置核对

若你的 MySQL 密码**不是** `123456`，需修改配置文件：

`backend/src/main/resources/application-dev.yml`

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/college_elective?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: root
    password: 你的密码        # ← 修改这里

  data:
    redis:
      host: localhost
      port: 6379
      password:               # ← Redis 有密码时填写
      database: 0
```

> 出现 `Public Key Retrieval is not allowed` 错误时，确认连接串中包含
> `allowPublicKeyRetrieval=true`（项目默认已包含）。

## 9. 常见问题

### 9.1 后端启动报 `Communications link failure`

MySQL 未启动或连接串错误。

```powershell
Get-Service MySQL80      # 确认服务运行
net start MySQL80        # 手动启动
```

### 9.2 后端启动报 `Access denied for user 'root'@'localhost'`

密码不匹配。修改 `application-dev.yml` 中的 `password`。

### 9.3 登录返回 500，日志显示 `Table 'college_elective.xxx' doesn't exist`

未执行建表脚本。执行 `scripts/init-db.sql`。

### 9.4 登录成功但立刻失效

Redis 未启动或数据被清空。令牌白名单存储在 Redis 中：

```powershell
Get-Service Memurai      # 或 Redis
redis-cli ping
```

### 9.5 `Public Key Retrieval is not allowed`

MySQL 8 的认证插件问题。确认连接串含 `allowPublicKeyRetrieval=true`，
或将 root 用户改为 `mysql_native_password`：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';
FLUSH PRIVILEGES;
```

### 9.6 前端接口 500 但后端日志无异常

前端开发代理默认指向 `http://localhost:8080`。检查：

- `frontend/.env.development` 中 `VITE_PROXY_TARGET` 是否正确
- 后端是否真的在 8080 端口运行

### 9.7 端口被占用

```powershell
# 查出占用进程
Get-NetTCPConnection -LocalPort 8080 -State Listen | Select-Object OwningProcess
Get-Process -Id <PID>

# 结束进程
Stop-Process -Id <PID> -Force
```

## 10. 快速检查清单

完成安装后逐项确认：

- [ ] `Get-Service MySQL80` 显示 Running
- [ ] `Test-NetConnection localhost -Port 3306` 返回 True
- [ ] `redis-cli ping` 返回 PONG
- [ ] 应用启动时日志出现「数据库表结构初始化完成」或「N 张表均已存在」
- [ ] 基础数据与演示数据已导入（`sys_log` 表有 20+ 条记录）
- [ ] 后端启动无异常，控制台输出「启动成功」
- [ ] `curl` 登录接口返回 `code=200`
- [ ] 前端页面可正常登录并跳转首页
