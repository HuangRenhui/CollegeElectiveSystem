# 数据库设计文档

> 数据库：MySQL 8.0 · 字符集：utf8mb4 · 排序规则：utf8mb4_general_ci
> 完整 DDL 见 `backend/src/main/resources/db/schema.sql`，初始化数据见 `backend/src/main/resources/db/data.sql`。

## 3. 表结构详情

### 3.1 sys_user 系统用户

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | NOT NULL, UNIQUE | 登录账号（学号/工号/管理员账号） |
| password | VARCHAR(200) | NOT NULL | 密码（DelegatingPasswordEncoder） |
| real_name | VARCHAR(50) | NOT NULL | 真实姓名 |
| role | VARCHAR(20) | NOT NULL, INDEX | STUDENT / TEACHER / ADMIN |
| gender | TINYINT | DEFAULT 0 | 0-未知 1-男 2-女 |

### 3.14 course_review 课程评价

> ✅ 本表已在 `db/schema.sql` 中定义，开发环境由 `DatabaseInitializer` 自动创建。
> 完整设计说明见 [待实现功能.md · 4.2 数据模型](./待实现功能.md#42-数据模型已新增)。

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK | 主键 |
| selection_id | BIGINT | NOT NULL, UNIQUE | 选课记录ID（一选课一评价） |
| student_id | BIGINT | NOT NULL, INDEX | 学生ID |
| course_id | BIGINT | NOT NULL, INDEX | 课程ID |
| teacher_id | BIGINT | INDEX | 授课教师ID（冗余，便于按教师统计） |
| semester_id | BIGINT | NOT NULL, INDEX | 学期ID |
| score_content | TINYINT | NOT NULL DEFAULT 5 | 教学内容（1-5 分） |
| score_teaching | TINYINT | NOT NULL DEFAULT 5 | 教学方法（1-5 分） |
| score_attitude | TINYINT | NOT NULL DEFAULT 5 | 教学态度（1-5 分） |
| score_gain | TINYINT | NOT NULL DEFAULT 5 | 学习收获（1-5 分） |
| average_score | DECIMAL(3,1) | NOT NULL DEFAULT 0.0 | 综合评分（四维平均） |
| content | VARCHAR(500) | | 文字评价（5-500 字） |
| anonymous | TINYINT | NOT NULL DEFAULT 1 | 0-实名 1-匿名 |
| status | TINYINT | NOT NULL DEFAULT 1 | 1-已提交 2-已公开 3-已隐藏 |
| submit_time | DATETIME | | 提交时间 |
| create_time / update_time | DATETIME | NOT NULL | 审计字段 |

**索引**：`uk_selection_id(selection_id)`、`idx_course_status(course_id, status)`、
`idx_teacher_semester(teacher_id, semester_id)`、`idx_student_semester(student_id, semester_id)`。

> **本表是全库唯一不含 `deleted` 字段的业务表**，这与项目「统一逻辑删除」的约定不同，
> 属于刻意设计。原因：`selection_id` 上建有唯一索引以保证「一选课一评价」，
> 若采用逻辑删除，被删除记录仍占用该唯一键，学生撤回评价后将**无法重新提交**。
> 因此评价删除一律为物理删除，实体 `CourseReview` 也**刻意不继承 `BaseEntity`**
> （基类带 `@TableLogic`，会使 MyBatis-Plus 自动追加 `deleted = 0` 条件而报错）。

> **`average_score` 冗余存储**：为四维评分的算术平均（保留 1 位小数），
> 由后端计算写入，便于列表排序与统计查询，避免每次实时聚合。

## 4. 索引设计说明

| 表 | 索引 | 用途 |
| --- | --- | --- |
| `sys_user` | `uk_username` | 登录查询 |
| `sys_user` | `idx_role`, `idx_status` | 按角色/状态筛选 |
| `course` | `uk_course_code_semester` | 防同学期重复课程编号 |
| `course` | `idx_semester_id`, `idx_teacher_id`, `idx_dept_id` | 多条件筛选 |
| `course_schedule` | `idx_semester_day` | 按学期+星期查询课表 |
| `course_selection` | `uk_student_course_semester` | 防重复选课 + 按学生查课表 |
| `course_selection` | `idx_student_semester` | 学生学期选课列表 |
| `course_selection` | `idx_course_id` | 课程选课名单 |
| `course_grade` | `uk_selection_id` | 一对一关联 |
| `course_grade` | `idx_student_semester` | 学生成绩单 |
| `notice` | `idx_status_publish` | 公告列表排序查询 |
| `sys_log` | `idx_create_time` | 日志归档清理 |
| `course_review` | `uk_selection_id` | 一选课一评价，防重复提交（并发兜底） |
| `course_review` | `idx_course_status` | 课程评价汇总与公开列表 |
| `course_review` | `idx_teacher_semester` | 教师评价汇总 |
| `course_review` | `idx_student_semester` | 学生评价列表与撤回 |

## 5. 数据一致性策略

| 数据 | 主数据源 | 副本 | 一致性保障 |
| --- | --- | --- | --- |
| 课程剩余容量 | Redis | `course.selected_count` | 选课/退课同步 + 每 5 分钟定时校正 |
| 选课关系 | `course_selection` | Redis Set | 唯一索引兜底 + 缓存回源 |
| 成绩 | `course_grade` | `course_selection.score` | 录入时同步写入 |
| 令牌状态 | Redis 白名单 | - | 登录/续期/注销时维护 |
