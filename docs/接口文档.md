# API 接口文档

> 基础路径：`http://localhost:8080/api`
> 在线调试：`http://localhost:8080/api/doc.html`
> 除登录接口外，所有接口需在请求头携带：`Authorization: Bearer {token}`

## 通用约定

### 统一响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2026-09-11 10:30:00",
  "success": true
}
```

### 分页响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [],
    "total": 100,
    "current": 1,
    "size": 10,
    "pages": 10
  },
  "success": true
}
```

### 状态码

| 状态码 | 说明 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数校验失败 |
| 401 | 未登录或登录已过期 |
| 403 | 没有操作权限 |
| 404 | 请求资源不存在 |
| 405 | 请求方法不支持 |
| 2001 | 账号或密码错误 |
| 2002 | 账号已被禁用 |
| 2003 | 无效的身份凭证 |
| 2004 | 原密码不正确 |
| 2005 | 登录账号已存在 |
| 2007 | 当前身份无法执行该操作 |
| 3001 | 课程不存在或已下架 |
| 3002 | 课程余量不足 |
| 3003 | 已选择该课程 |
| 3004 | 尚未选择该课程 |
| 3005 | 上课时间冲突 |
| 3006 | 不在选课开放时间内 |
| 3007 | 选课通道已关闭 |
| 3008 | 选课学分超出上限 |
| 3009 | 该课程不允许退选 |
| 3010 | 课程缓存尚未就绪 |
| 4001 | 成绩记录不存在 |
| 4002 | 成绩已发布，无法修改 |
| 4003 | 成绩取值非法 |
| 4004 | 不是该课程的授课教师 |
| 5001 | 数据不存在 |
| 5002 | 数据已存在 |
| 5003 | 该数据禁止被删除或修改 |
| 5006 | 该功能尚未实现（选课/成绩模块实现前返回） |

## 01 认证与个人中心

### 1.1 用户登录

`POST /auth/login` · 无需认证

**请求体**

```json
{
  "username": "2026010101",
  "password": "123456"
}
```

**响应**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "tokenType": "Bearer",
    "expiresIn": 7200,
    "userId": "101",
    "username": "2026010101",
    "realName": "刘思远",
    "role": "STUDENT",
    "avatar": null
  },
  "success": true
}
```

### 1.2 退出登录

`POST /auth/logout` · 需认证

响应：`{ "code": 200, "message": "退出成功" }`

### 1.3 获取当前用户信息

`GET /auth/info` · 需认证

**响应 data**

```json
{
  "userId": "101",
  "username": "2026010101",
  "realName": "刘思远",
  "role": "STUDENT",
  "gender": 1,
  "phone": "13900000101",
  "email": "2026010101@stu.edu.cn",
  "stuNo": "2026010101",

  "className": "计科2601",
  "totalCredit": 0.0,
  "deptName": "计算机科学与技术学院"
}
```

### 1.4 修改密码

`PUT /auth/password` · 需认证

```json
{
  "oldPassword": "123456",
  "newPassword": "abc123456",
  "confirmPassword": "abc123456"

```

### 1.5 修改个人资料

`PUT /auth/profile` · 需认证

```json
{
  "realName": "刘思远",
  "gender": 1,
  "phone": "13900000101",
  "email": "2026010101@stu.edu.cn"
}
```

## 02 学生选课

### 2.1 分页查询可选课程

`GET /student/courses` · STUDENT

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pageNum | Long | 否 | 页码，默认 1 |
| pageSize | Long | 否 | 每页条数，默认 10 |
| courseName | String | 否 | 课程名称（模糊） |
| courseCode | String | 否 | 课程编号（模糊） |
| deptId | Long | 否 | 开课院系 |
| courseType | String | 否 | REQUIRED/ELECTIVE/PUBLIC |
| semesterId | Long | 否 | 学期 |
| onlyAvailable | Boolean | 否 | 仅看有余量 |

**响应 data.records[]**

```json
{
  "id": "1",
  "courseCode": "GE1001",
  "courseName": "Python程序设计基础",
  "credit": 3.0,
  "hours": 48,
  "courseType": "PUBLIC",
  "examType": "EXAM",
  "maxCapacity": 60,
  "selectedCount": 0,
  "teacherName": "张明远",
  "deptName": "计算机科学与技术学院",
  "scheduleText": "周一 第1-2节 实验楼B301；周三 第3-4节 实验楼B301",
  "remainingCapacity": 60,
  "selected": false
}
```

### 2.2 查询课程详情

`GET /student/courses/{id}` · STUDENT

响应额外包含 `schedules` 排课明细数组。

### 2.3 选课

`POST /student/courses/{courseId}/select` · STUDENT

**成功响应**

```json
{
  "code": 200,
  "message": "选课成功",
  "data": {
    "success": true,
    "courseId": "1",
    "courseName": "Python程序设计基础",
    "remainingCapacity": 59,
    "message": "选课成功"
  },
  "success": true
}
```

**可能的业务错误**

| 状态码 | 场景 |
| --- | --- |
| 3002 | 课程已满 |
| 3003 | 已选过该课程 |
| 3005 | 与已选课程时间冲突（message 含冲突明细） |
| 3006 | 不在选课开放时间内 |
| 3007 | 选课通道已关闭 |
| 3008 | 选课学分超限 |
| 3010 | 缓存未就绪 |

### 2.4 退课

`POST /student/courses/{courseId}/drop` · STUDENT

**业务约束**

- 课程 `selectable = 0` 时禁止退选（返回 3009）；
- 已录入成绩的课程禁止退选。

### 2.5 选课时间冲突预检

`GET /student/courses/{courseId}/conflict` · STUDENT

**响应 data**

```json
[
  {
    "conflictCourseName": "数据结构与算法",
    "description": "与《数据结构与算法》上课时间冲突（周一 第1-2节）",
    "dayOfWeek": 2,
    "sectionText": "1-2节",
    "weekText": "1-16周"
  }
]
```

> 无冲突时返回空数组。

### 2.6 我的选课记录

`GET /student/selections` · STUDENT

| 参数 | 说明 |
| --- | --- |
| pageNum / pageSize | 分页 |
| semesterId | 学期筛选 |
| status | 0-已退选 1-已选课 2-已修完 |

### 2.7 我的课表

`GET /student/timetable` · STUDENT

| 参数 | 说明 |
| --- | --- |
| semesterId | 学期（不传则取当前学期） |

**响应 data[]**

```json
{
  "courseId": "1",
  "courseName": "Python程序设计基础",
  "courseCode": "GE1001",
  "teacherName": "张明远",
  "location": "实验楼B301",
  "dayOfWeek": 1,
  "startSection": 1,
  "endSection": 2,
  "startWeek": 1,
```

## 04 教师工作台

### 4.1 我的授课课程

`GET /teacher/courses` · TEACHER

| 参数 | 说明 |
| --- | --- |
| pageNum / pageSize | 分页 |
| semesterId | 学期筛选 |

### 4.2 课程学生名单（分页）

`GET /teacher/courses/{courseId}/students` · TEACHER

| 参数 | 说明 |
| --- | --- |
| pageNum / pageSize | 分页 |
| keyword | 姓名或学号模糊搜索 |

### 4.3 课程选课记录列表

`GET /teacher/courses/{courseId}/selections` · TEACHER

### 4.4 成绩录入单

`GET /teacher/courses/{courseId}/grade-sheet` · TEACHER

返回该课程全部学生的当前成绩状态（无成绩时字段为 null）。

### 4.5 批量录入成绩

`POST /teacher/grades/input` · TEACHER

```json
{
  "courseId": 1,
  "items": [
    {
      "selectionId": 1,
      "studentId": 1,
      "usualScore": 90,
      "examScore": 85,
      "remark": "表现优秀"
    }
  ]
}
```

**业务规则**

- 成绩必须在 0-100 之间，否则返回 4003；
- 已发布 / 已归档的成绩禁止修改，返回 4002；
- 保存后状态为「草稿」，学生不可见；
- 总评 = 平时 × 0.3 + 期末 × 0.7。

### 4.6 发布成绩

`POST /teacher/courses/{courseId}/grades/publish` · TEACHER

**业务约束**：存在未录入总评成绩的学生时禁止发布。

### 4.7 撤回成绩发布

`POST /teacher/courses/{courseId}/grades/revoke` · TEACHER

将已发布成绩改回草稿状态。

### 4.8 教师课表

`GET /teacher/timetable` · TEACHER

| 参数 | 说明 |
| --- | --- |
| semesterId | 学期（不传则取当前学期） |

## 05 课程管理（管理员）

### 5.1 分页查询课程

`GET /admin/courses` · ADMIN

参数同 [2.1](#21-分页查询可选课程)，额外支持 `courseCode`、`status`。

### 5.2 课程详情

`GET /admin/courses/{id}` · ADMIN

### 5.3 新增课程

`POST /admin/courses` · ADMIN

```json
{
  "courseCode": "GE7001",
  "courseName": "Web前端开发",
  "semesterId": 3,
  "deptId": 1,
  "teacherId": 1,
  "credit": 2.5,
  "hours": 40,
  "courseType": "ELECTIVE",
  "examType": "CHECK",
  "maxCapacity": 50,
  "textbook": "《Vue.js设计与实现》",
  "introduce": "前端工程化与组件化开发实践。",
  "selectable": 1,
  "status": 1,
  "schedules": [
    {
      "classroomId": 4,
      "dayOfWeek": 3,
      "startSection": 5,
      "endSection": 6,
      "startWeek": 1,
      "endWeek": 16,
      "weekType": "ALL"
    }
  ]
}
```

**业务校验**

- 同一学期下课程编号唯一，否则返回 5002；
- 排课时段内部不可重叠；
- 教师同一时段不可重复排课，否则返回 3012；
- 教室同一时段不可被占用，否则返回 3012。

### 5.4 修改课程

`PUT /admin/courses` · ADMIN

请求体同新增，需携带 `id`。容量不可小于已选人数。

### 5.5 删除课程

`DELETE /admin/courses/{id}` · ADMIN

已存在有效选课记录时禁止删除（返回 5003）。

### 5.6 变更课程状态

`PUT /admin/courses/{id}/status/{status}` · ADMIN

`status`：0-下架，1-正常，2-已结课。

### 5.7 预热选课缓存

`POST /admin/courses/cache/preload` · ADMIN

| 参数 | 说明 |
| --- | --- |
| semesterId | 学期（不传则预热全部正常状态课程） |

> 建议在开放选课前执行，将课程余量与已选集合写入 Redis。

### 5.8 手动同步选课人数

`POST /admin/courses/selection/sync` · ADMIN

校正数据库 `selected_count` 与 Redis 余量。

### 5.9 首页统计数据

`GET /admin/courses/statistics` · ADMIN

| 参数 | 说明 |
| --- | --- |
| semesterId | 学期 |

**响应 data**

```json
{
  "studentCount": 5,
  "teacherCount": 5,
  "courseCount": 10,
  "selectionCount": 0,
  "deptCount": 5,
  "currentSemesterCourseCount": 10,
  "hotCourses": [
    { "courseId": "6", "courseName": "市场营销学", "teacherName": "王雅琴",
      "maxCapacity": 100, "selectedCount": 0, "rate": 0.0 }
  ],
  "deptDistribution": [{ "name": "计算机科学与技术学院", "value": 3 }],
```

## 附：典型调用序列

### 学生选课完整流程

```
1. POST /auth/login                        → 获取 token
2. GET  /common/semesters/current          → 确认当前学期与选课窗口
3. GET  /student/courses?onlyAvailable=true → 浏览有余量课程
4. GET  /student/courses/{id}/conflict     → 冲突预检（可选）
5. POST /student/courses/{id}/select       → 选课
6. GET  /student/timetable                 → 查看最新课表
```

### 教师成绩录入完整流程

```
1. POST /auth/login                                  → 获取 token
2. GET  /teacher/courses?semesterId={id}             → 获取授课列表
3. GET  /teacher/courses/{courseId}/grade-sheet      → 获取成绩录入单
4. POST /teacher/grades/input                        → 保存草稿
5. POST /teacher/courses/{courseId}/grades/publish   → 发布成绩
```

### 管理员开放选课流程

```
1. POST /auth/login                                     → 获取 token
2. POST /admin/semesters                                → 配置学期选课时间窗口
3. PUT  /admin/semesters/{id}/current                   → 设为当前学期
4. POST /admin/courses/cache/preload?semesterId={id}    → 预热选课缓存
5. PUT  /admin/system/selection-switch/on               → 开启选课通道
```
