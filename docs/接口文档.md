# API 接口文档

> 基础路径：`http://localhost:8080/api`
> 在线调试：`http://localhost:8080/api/doc.html`
> 除登录接口外，所有接口需在请求头携带：`Authorization: Bearer {token}`

## 通用约定

### 统一响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2026-09-11 10:30:00",
  "success": true
}
```

### 分页响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [],
    "total": 100,
    "current": 1,
    "size": 10,
    "pages": 10
  },
  "success": true
}
```

### 状态码

| 状态码 | 说明 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数校验失败 |
| 401 | 未登录或登录已过期 |
| 403 | 没有操作权限 |
| 404 | 请求资源不存在 |
| 405 | 请求方法不支持 |
| 2001 | 账号或密码错误 |
| 2002 | 账号已被禁用 |
| 2003 | 无效的身份凭证 |
| 2004 | 原密码不正确 |
| 2005 | 登录账号已存在 |
| 2007 | 当前身份无法执行该操作 |
| 3001 | 课程不存在或已下架 |
| 3002 | 课程余量不足 |
| 3003 | 已选择该课程 |
| 3004 | 尚未选择该课程 |
| 3005 | 上课时间冲突 |
| 3006 | 不在选课开放时间内 |
| 3007 | 选课通道已关闭 |
| 3008 | 选课学分超出上限 |
| 3009 | 该课程不允许退选 |
| 3010 | 课程缓存尚未就绪 |
| 3011 | 选课窗口尚未开放 |
| 3012 | 排课时间冲突（教师或教室占用） |
| 4001 | 成绩记录不存在 |
| 4002 | 成绩已发布，无法修改 |
| 4003 | 成绩取值非法 |
| 4004 | 不是该课程的授课教师 |
| 5001 | 数据不存在 |
| 5002 | 数据已存在 |
| 5003 | 该数据禁止被删除或修改 |
| 5005 | 当前学期未设置 |
| 5006 | 该功能尚未实现（选课/成绩模块实现前返回） |
| 6001 | 评价记录不存在 |
| 6002 | 已评价过该课程 |
| 6003 | 课程未修完，暂无评价资格 |
| 6004 | 评价评分或内容不合法 |
| 6005 | 评价已被隐藏，无法修改 |

### 4.4 成绩录入单

`GET /teacher/courses/{courseId}/grade-sheet` · TEACHER

返回该课程全部学生的当前成绩状态（无成绩时字段为 null）。

### 4.5 批量录入成绩

`POST /teacher/grades/input` · TEACHER

```json
{
  "courseId": 1,
  "items": [
    {
      "selectionId": 1,
      "studentId": 1,
      "usualScore": 90,
      "examScore": 85,
      "remark": "表现优秀"
    }
  ]
}
```

**业务规则**

- 成绩必须在 0-100 之间，否则返回 4003；
- 已发布 / 已归档的成绩禁止修改，返回 4002；
- 保存后状态为「草稿」，学生不可见；
- 总评 = 平时 × 0.3 + 期末 × 0.7。

### 4.6 发布成绩

`POST /teacher/courses/{courseId}/grades/publish` · TEACHER

**业务约束**：存在未录入总评成绩的学生时禁止发布。

### 4.7 撤回成绩发布

`POST /teacher/courses/{courseId}/grades/revoke` · TEACHER

将已发布成绩改回草稿状态。

### 4.8 教师课表

`GET /teacher/timetable` · TEACHER

| 参数 | 说明 |
| --- | --- |
| semesterId | 学期（不传则取当前学期） |

### 5.3 新增课程

`POST /admin/courses` · ADMIN

```json
{
  "courseCode": "GE7001",
  "courseName": "Web前端开发",
  "semesterId": 3,
  "deptId": 1,
  "teacherId": 1,
  "credit": 2.5,
  "hours": 40,
  "courseType": "ELECTIVE",
  "examType": "CHECK",
  "maxCapacity": 50,
  "textbook": "《Vue.js设计与实现》",
  "introduce": "前端工程化与组件化开发实践。",
  "selectable": 1,
  "status": 1,
  "schedules": [
    {
      "classroomId": 4,
      "dayOfWeek": 3,
      "startSection": 5,
      "endSection": 6,
      "startWeek": 1,
      "endWeek": 16,
      "weekType": "ALL"
    }

```

- 同一学期下课程编号唯一，否则返回 5002；
- 排课时段内部不可重叠；
- 教师同一时段不可重复排课，否则返回 3012；
- 教室同一时段不可被占用，否则返回 3012。

### 5.4 修改课程

`PUT /admin/courses` · ADMIN

### 5.6 变更课程状态

### 13.2 提交 / 修改评价

`POST /student/reviews` · STUDENT

```json

  "courseId": 1,
  "scoreContent": 5,
  "scoreTeaching": 4.5,
```

**业务规则**

- 四个维度评分范围 **1-5 分**（支持半星），越界或缺失返回 `6004`；
- 文字评价长度 **5-500** 字，超出返回 `6004`；
- 综合评分 = 四维平均，保留 1 位小数（**后端计算，DTO 不接收该字段**，防止前端篡改）；
- **仅可评价本人已修完**（`course_selection.status = 2`）的课程，否则返回 `6003`；
- 每门课程仅一份评价，重复提交返回 `6002`；带 `id` 表示修改；
- 修改后状态**回退为「已提交」**，需管理员重新公开（防止先好评后改差评绕过审核）；
- 只能修改本人评价，越权返回 `403`；已隐藏评价返回 `6005`；

| 状态码 | 场景 |
| --- | --- |
| 6002 | 已评价过该课程 |
| 6003 | 课程未修完，暂无评价资格 |
| 6004 | 评分或文字长度不合法 |
| 6005 | 评价已被管理员隐藏，无法修改 |

### 13.3 我的评价列表

`GET /student/reviews` · STUDENT

| 参数 | 说明 |
| --- | --- |
| semesterId | 学期筛选 |

返回 `CourseReviewVO[]`，含 `id / courseId / courseCode / courseName / teacherName /
scoreContent / scoreTeaching / scoreAttitude / scoreGain / averageScore / content /
anonymous / status / submitTime`。

> 便于确认填写内容；查看他人评价（13.7）时一律匿名。

### 13.5 撤回我的评价

`DELETE /student/reviews/{id}` · STUDENT

## 15 评价管理（管理员）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/admin/reviews` | 分页查询（keyword / semesterId / status / scoreLevel） |
| PUT | `/admin/reviews/{id}/status/{status}` | 公开(2) / 隐藏(3)，`reason` 必填 |
| DELETE | `/admin/reviews/{id}` | 删除评价，`reason` 必填 |
| GET | `/admin/reviews/statistics` | 评价统计（semesterId） |

### 15.1 分页查询评价

`GET /admin/reviews` · ADMIN

| 参数 | 说明 |
| --- | --- |
| pageNum / pageSize | 分页 |
| keyword | 课程名称 / 编号 / 教师名模糊搜索 |
| semesterId | 学期 |
| status | 0-草稿 1-已提交 2-已公开 3-已隐藏 |
| scoreLevel | `high`(≥4.5) / `good`(3.5-4.4) / `normal`(2.5-3.4) / `low`(<2.5) |

返回记录额外含 `studentName`、`stuNo`（管理员审计需要），
前端对匿名评价仍展示「匿名同学」。

### 15.2 变更评价状态

`PUT /admin/reviews/{id}/status/{status}?reason=xxx` · ADMIN

| status | 含义 |
| --- | --- |
| 2 | 公开（教师端可见） |
| 3 | 隐藏（教师端不可见，学生不可修改） |

`reason` 长度 ≥ 2，随操作日志一并落库。

### 15.3 删除评价

`DELETE /admin/reviews/{id}?reason=xxx` · ADMIN

`reason` 长度 ≥ 2，与「变更状态」同口径校验。删除后该学生可重新提交同一门课程的评价。

> **已实现为物理删除**：`course_review` 表未定义 `deleted` 字段，
> 因此 `removeById()` 执行真实 DELETE，`selection_id` 唯一键随之释放。

## 附：典型调用序列

### 学生选课完整流程

```
1. POST /auth/login                        → 获取 token
2. GET  /common/semesters/current          → 确认当前学期与选课窗口
3. GET  /student/courses?onlyAvailable=true → 浏览有余量课程
4. GET  /student/courses/{id}/conflict     → 冲突预检（可选）
5. POST /student/courses/{id}/select       → 选课
6. GET  /student/timetable                 → 查看最新课表
```

### 教师成绩录入完整流程

```
1. POST /auth/login                                  → 获取 token
2. GET  /teacher/courses?semesterId={id}             → 获取授课列表
3. GET  /teacher/courses/{courseId}/grade-sheet      → 获取成绩录入单
4. POST /teacher/grades/input                        → 保存草稿
5. POST /teacher/courses/{courseId}/grades/publish   → 发布成绩
```

### 管理员开放选课流程

```
1. POST /auth/login                                     → 获取 token
2. POST /admin/semesters                                → 配置学期选课时间窗口
3. PUT  /admin/semesters/{id}/current                   → 设为当前学期
4. POST /admin/courses/cache/preload?semesterId={id}    → 预热选课缓存
5. PUT  /admin/system/selection-switch/on               → 开启选课通道
```

### 学生提交教学评价流程

```
1. POST /auth/login                             → 获取 token
2. GET  /student/reviews/pending                → 查看待评价课程
3. POST /student/reviews                        → 填写并提交四维评价
4. GET  /student/reviews                        → 确认提交结果（可修改/撤回）
```

### 管理员审核与统计评价流程

```
1. POST /auth/login                                       → 获取 token
2. GET  /admin/reviews?status=1                           → 查看已提交待审核评价
3. PUT  /admin/reviews/{id}/status/2?reason=内容合规      → 公开评价
4. PUT  /admin/reviews/{id}/status/3?reason=含不当言论    → 隐藏违规评价
5. GET  /admin/reviews/statistics?semesterId={id}         → 查看全校评价统计
```
